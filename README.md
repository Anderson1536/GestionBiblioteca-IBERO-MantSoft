 **Sistema gestión biblioteca**

**Historias de usuario**

 

1. **Validación de datos:** Verificar que el ISBN no exista antes de agregar un libro, para evitar duplicados. 

2. **Buscar por género:** Como usuario de la biblioteca se necesita poder buscar libros por genero para encontrar libros de una categoría especifica.  

3. **Mostrar disponibilidad del libro:** Como usuario quiero saber si un libro está disponible o prestado para verificar si puedo solicitarlo. 

4. **Agregar y eliminar usuarios:** Como administrador se necesita poder agregar y eliminar usuarios para mantener actualizada la base o información de usuarios. 

5. **Reporte de préstamos:** Como administrados se necesita poder visualizar todos los prestamos activos para controlar y verificar que libros están fuera de la biblioteca.
